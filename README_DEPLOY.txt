AUTO GEIST STUDIO V6 STABLE

1. In GitHub sterge fisierele vechi si incarca TOATE fisierele si folderul public din acest ZIP in radacina repository-ului.
2. Render: Environment Docker (nu Node). Daca serviciul exista deja, Manual Deploy -> Clear build cache & deploy.
3. Deschide /health si verifica version 6.0.0, ffmpeg true.
4. Deschide aplicatia in Safari in tab nou; daca apare V4/V5, inchide vechiul shortcut si sterge datele site-ului din Safari.
5. Filmeaza initial 2-3 cadre pentru test, apoi 15.

IMPORTANT: Exportul este 720x1280 pentru stabilitate pe planul gratuit 512MB, nu 1080p. Serverul poate procesa un singur Reel simultan. Nu inchide Safari in timpul uploadului si montajului. Cadrele sunt tinute in memoria tabului, nu stocate permanent pe telefon.
Zoom: este folosit doar zoom hardware suportat de camera; daca browserul nu permite, zoom-ul ramane 1x.
Limite: pe Render free, serviciul poate adormi, poate reporni sau poate depasi RAM/disk pentru fisiere mari. Pentru fiabilitate garantata este necesar un plan cu mai multe resurse.
